# honest-agent example

A demo agent answering questions about DuckDB's TPC-H sample data (customers,
orders, line items, suppliers, nations), and six evals that check it. It runs
on your machine: no account or server needed, only a model API key.

## Run it

1. Put your API key in `.env` (`ANTHROPIC_API_KEY`, or `OPENAI_API_KEY` if you
   chose OpenAI).
2. `honest-agent run`: the agent answers the six questions. With the cheap
   model set in `honest_agent_config.yml`, a run costs a few cents.
3. `honest-agent report`, then `honest-agent serve`: the results in your
   browser.
4. `honest-agent logs --eval-id top_nations_last_year`: every call the agent
   and the grader made for one eval.

## What the evals show

| Eval | Grading | Provenance | Expected outcome |
|---|---|---|---|
| `top_segment` | `contains`: the answer must name BUILDING | reads `customer` | pass |
| `revenue_1997` | `extract_match` with an absolute `tolerance` | reads `lineitem` and `orders` | pass |
| `avg_order_total_1996` | `extract_match` with `tolerance_percent` | reads `orders` | pass |
| `order_total_1995` | `extract_match` | expects `orders` **and** `lineitem` | **fails provenance** with a correct answer: `orders` alone answers it, so the expectation is too strict on purpose |
| `top_ship_mode_1995` | `llm_judge`, which gives partial credit | not checked | TRUCK and MAIL are tied: **passes** when the agent spots the tie, **partial credit** (about 0.5, below the minimum) when it names only one |
| `top_nations_last_year` | `llm_judge` | reads `orders`, `customer`, `nation` | **fails accuracy**: "last year" is ambiguous, and the agent tends to pick 1998, the latest year in the data, instead of 1997, the last full one |

Results vary a little from run to run: the agent is a model. Two things to
know when reading them:

- Provenance counts every table the agent selected from while working, not
  only the query behind its answer. If it peeks at `lineitem` along the way,
  `order_total_1995` passes provenance.
- `show tables` and `describe` don't count as reading a table; a `select`
  does.

## What's in this folder

- `honest_agent_config.yml`: one target, `demo`, which starts honest-agent's
  demo MCP server on `warehouse.duckdb`.
- `warehouse.duckdb`: the TPC-H sample data, generated by DuckDB's `tpch`
  extension.
- `evals/example_evals.yml`: the six evals, with comments.
- `.env`: your API key.

**The demo MCP server is for trying honest-agent, not for real data.** It runs
any read-only SQL the model sends, with no authentication and no limits besides
a 200-row cap. honest-agent evaluates your agent through your agent's own MCP
server. To set that up in a new folder: `honest-agent init`.
